# Plant Methods Submission Checklist

## Manuscript type and structure

- [x] Article type selected: Methodology.
- [x] Title identifies the computational method and application.
- [x] Structured abstract uses Background, Results and Conclusions and is below 350 words.
- [x] Three to ten keywords are provided.
- [x] Main sections follow Background, Methods, Results, Discussion and Conclusions.
- [x] Declarations contains every required subsection.
- [x] References use numbered citation order.
- [x] Figure titles are below 15 words and legends are below 300 words.
- [x] Additional files are cited and described.

## Scientific and evidence checks

- [x] Fixed encoder, downstream decoder-fitting roles and held-out evaluation roles are explicitly separated.
- [x] Frozen-encoder leave-species decoder result is distinguished from global context sensitivity.
- [x] All-cell, coverage and covered-label metrics are reported together.
- [x] Few-shot support cells are excluded from query evaluation.
- [x] Arabidopsis blind inference is not described as external accuracy.
- [x] Wheat and Sorghum results are labelled target-supervised adaptation.
- [x] scPlantLLM is described as a same-study reference, not a universal ranking.
- [x] Negative source-only transfer is retained in the supplement.
- [x] No Snow Lotus-specific atlas or performance claim is made.
- [x] Current hardware is reported as NVIDIA RTX 4090.

## Files prepared

- [x] English main manuscript in Markdown and Word.
- [x] Supporting Information in Markdown and Word.
- [x] Cover letter in Markdown and Word.
- [x] Supplementary Figs. S1-S11 combined into one PDF.
- [x] Supplementary Tables S1-S27 workbook identified.
- [x] Figure source-data workbook identified.
- [x] Seven main figures identified as upload-ready PDF files.
